## Motion notes

- Final reveal uses the denser horizontal-band crescent-`D` wordmark.
- The `O` mark is steadier: idle scale pulsing was removed and the mark stays centered through the hold.
- Ring closure is slower, with a longer wave-viewing segment before the wordmark reveal.

Motion timing:
- total duration: ~6.92s
- ring closure completes around 2.70s
- wordmark reveal begins around 5.30s
