# OpenDream animation bundle

This bundle contains the production motion assets for OpenDream brand surfaces.

## Use in product

- `svg/opendream_loop_light_rolling_waves.svg`
- `svg/opendream_loop_dark_rolling_waves.svg`

Use these for lightweight ambient product motion, especially loading states. Keep them decorative, theme-aware, and paired with a static fallback for reduced-motion users.

## Use in docs

- `video/opendream_splash_wordmark_light_preview.gif`
- `video/opendream_splash_wordmark_dark_preview.gif`
- `posters/opendream_splash_wordmark_light_poster.png`
- `posters/opendream_splash_wordmark_dark_poster.png`

Use the GIF previews for Markdown surfaces that cannot embed video controls reliably. Use posters as thumbnails when autoplay would be too heavy.

## Use in video and release assets

- `video/opendream_splash_wordmark_light_1920x1080.mp4`
- `video/opendream_splash_wordmark_dark_1920x1080.mp4`

Use the MP4 splash files for launch videos, social cuts, release notes, and edited demo reels. They are not loaded by the web app.

## Source

The splash extends the wave-viewing segment, settles the mark, then reveals the full wordmark. The final frame crossfades to the supplied wordmark asset for exact lockup fidelity.
