# 09-advanced-runtime-proof.md

## Goal
Prove the release exceeds note-oriented systems and survives multiple execution surfaces.

## Required evidence
- memory-excellence scorecard (from 439)
- execution-mode matrix
- repeated coding-task deltas by mode
- delegated-ingest correctness
- feature-radar / bug-radar / fix-radar correctness
- status/doc truthfulness checks

## Required comparison modes
- deterministic-only
- direct-provider
- codex-account
- claude-scheduled-task
- cursor-automation

## Minimum claim
OpenDream is not merely compatible with vendor runtimes; it provides a stronger memory control plane because the same verification, relation, reconciliation, and review model survives across them.
