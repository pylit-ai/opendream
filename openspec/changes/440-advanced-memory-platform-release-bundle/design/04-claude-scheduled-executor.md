# 04-claude-scheduled-executor.md

## Goal
Support recurring semantic work through Claude’s own scheduling surfaces.

## Supported submodes
- desktop scheduled task
- cloud scheduled task
- optional repo-oriented GitHub Actions path documented as an operator choice

## Generated surfaces
- prompt / command template
- schedule template
- delegated semantic envelope output contract
- feature mining, radar, and semantic-refresh examples

## Important distinction
Claude owns execution.
OpenDream owns memory ingestion, verification, review, and long-horizon memory control.
