# 06-release-positioning.md

## Positioning
This feature should be described as:
- a machine-local workspace catalog
- a first-party workspace dashboard
- a multi-repo operator convenience layer

It should not be described as:
- a cloud sync system
- a hidden global control plane
- a replacement for per-workspace state

## Benefit statement
The dashboard makes OpenDream usable across many repos without undermining the local-first trust model.
