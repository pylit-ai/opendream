# 08-review-and-observability.md

## Goal
Make memory falsifiable through UX.

## Required surfaces
- claim provenance and verification outcome
- relation clusters and supersession chains
- transcript probe traces
- reconciliation queue/results
- memory-hurt diagnostics
- index budget and generated-view health

## UX principles
- raw evidence remains visible
- queue reason before edit action
- graph is bounded and secondary, never a hairball-by-default
- every change links back to a run artifact
