# 07-procedural-memory-elevation.md

## Goal
Lean into one of OpenDream’s strongest advantages: procedural memory.

## Required fields
- workflow steps
- preconditions
- recovery steps
- anti-patterns
- success markers
- stale/invalidating conditions

## Retrieval behavior
Procedural memory should win when:
- the query is task/command/workflow shaped
- a strong reusable workflow exists
- its preconditions match the current context

## Why
Procedural memory is higher leverage for coding than treating everything as note cleanup.
