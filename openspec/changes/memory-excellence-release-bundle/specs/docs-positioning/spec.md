# docs-positioning/spec.md

## Requirements

### Requirement: truthful positioning
Docs MUST position OpenDream as a bounded, verified, auditable memory system.

#### Scenario: operator reads docs
- **WHEN** the operator reads README/FAQ/benchmark docs
- **THEN** the docs explain bounded startup memory, generated views, relation-aware truth handling, and release evidence
- **AND** they do not imply whole-transcript replay or markdown-only canonical memory
